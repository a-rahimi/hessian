# Archived runs

The Newton sweeps that produced `../summary-so-far.md`, kept for their `cmd.sh`
so each run remains reproducible.

Only `exp-002-batch-reuse-K3` and `exp-003-epsilon-sweep-down` kept a log, and
those two have been parsed into `results/<id>.csv` with the shared harness. The
other 53 runs saved nothing but their command, so their numbers survive only as
narrative in `../results.md` and the runs cannot be replotted. That is the reason
the convention in `../README.md` requires a CSV.
